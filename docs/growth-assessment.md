# 成长评价算法

依据国家卫健委 WS/T 423—2022《7岁以下儿童生长标准》[官方原文](https://www.nhc.gov.cn/fzs/c100048/202211/5001d7cf57774770a1d49c1df46a291f/files/1733125082501_81468.pdf)，采用第4.1节表1及附录A。适用于出生至未满7岁儿童。

## 生长水平与参考带

按性别及各自测量当天的已满月龄查附录A：年龄别体重A.1/A.2，年龄别身长或身高A.3/A.4。

| 区间 | 生长水平 |
| --- | --- |
| 小于P3 | 下 |
| P3 ≤ 值 < P25 | 中下 |
| P25 ≤ 值 < P75 | 中 |
| P75 ≤ 值 < P97 | 中上 |
| 值 ≥ P97 | 上 |

首页位置图与日/月趋势参考带统一使用P3～P97，P50为中位值。最高参考点为P97，超过它显示范围上方，不截断实际体重或身长，不推算P98、P99等数值。P97边界本身归“上”。面向家长保留简单等级与实际单位，不堆叠专业缩写。

## 首页分段百分位尺

采用附录A列出的P3、P10、P25、P50、P75、P90、P97七个节点，六个区间等宽排列，两端灰色区域表示表列范围以外。每段以其节点标注，图尺不把区间宽度解释为人口占比。

- 测量值等于某个官方表值时，标记落在对应节点；面向家长描述为“比约多少%的同月龄男宝宝/女宝宝重或长”。
- 测量值处于两个节点之间时，只在这两个节点之间做线性估算，四舍五入到整数百分位，并在首页比较文字前明确标注“估算”。这是应用的简化位置估算，不是官方表公布的精确百分位，也不是用LMS参数拟合的结果。
- 图中位置按同一对节点内的测量值比例放置，避免把整条P3至P97的测量范围一概视为均匀分布。小于P3或大于P97时放在两端灰区，明确显示“低于第3百分位”或“超过第97百分位”，不计算范围外的具体百分位。
- 百分位估算仅用于位置说明，不改动生长等级和胖瘦结论；分级继续比较原始测量值与官方阈值。测量月龄的查表策略、缺失标准不评价等规则保持一致。

## 营养状况中的胖瘦参考

**这部分为应用参考策略，不是原文第4.3节的营养诊断分级。** 原文第4.3节只提供标准差法；应用不把P3、P97等同于−2SD、+2SD，不再输出低体重、生长迟缓、超重、肥胖及其重度诊断分级。

- 年龄别体重低于P3：提示“体重偏低”。
- 年龄别身长/身高低于P3：提示“身长偏低”。
- 各取最近一次体重和身长，用两次测量中较新日期的月龄，查年龄别体重指数表A.9/A.10。体重指数低于P3提示“偏瘦”，达到或超过P97提示“偏胖”，其间无其他偏低提示时显示“胖瘦适中”。允许偏低与偏胖提示并存。体重等级“上”本身不等于偏胖。
- 体重指数=体重（千克）÷身长或身高（米）的平方。比较原始整数单位，使用“克×10000”和“阈值×10×毫米²”交叉相乘，不先四舍五入再判定。
- 缺少任一测量或有效标准时，不输出完整胖瘦结论；已有的偏低提示仍保留。
- 数据仅支持P3至P97，不能区分极端值的严重程度，异常或担心时复测并咨询儿保医生。

## 数据与日期

- 数据包含A.1～A.4、A.9～A.10及B.1～B.4、B.9～B.10，共12张表、528行、3696个原始阈值。页面默认与实际调用均为百分位法；标准差表保留供核验与明确指定的旧算法测试，页面不使用。
- 数据由`scripts/extract-growth-standard.py`从官方PDF生成；Poppler与pdfplumber独立提取结果逐项一致，校验行数、年龄点及数值递增；模块记录PDF的SHA256。不修改官方原数值，不提交个人数据。
- 已满月龄采用日历策略，出生当日0月，月末生日按目标月最后一天满月；不是原文给出的逐日算法。0～24月每月有表行，此后每3个月一行。缺少对应月龄时不插值、不外推、不借用附近年龄行。
- 趋势图与首页共用测量月龄和表值；月视图取该指标当月最后一次实测日，无实测时取月末，当前月取今天。每个日期独立画范围，不跨缺失标准行连接。体重千克×2换算为斤，实测克÷500，身长厘米。
- 缺性别或生日、无效测量、测量早于出生、满7岁或无对应月龄表行时不评价。
- 体重与身长各取最新值，不要求同日，也不回退至旧同日配对。相隔0～7天不额外提示；8天起说明天数、结果可能不够准确，并建议更新较旧指标。一周只是应用提示策略，不是准确度保证。
- 2岁以下躺着量身长，2岁起站立量身高；不自动换算测量姿势。所有结论仅供参考，不用于诊断。

## 验证

`npm test`覆盖原始表完整性、百分位全部行和分界等号、首页/趋势一致、体重指数整数边界、缺资料、日期差和月龄切换，并保留显式指定标准差法的独立边界测试。
